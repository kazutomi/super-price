# スーパー価格比較

品名ごとに、スーパー別の製造元・数量・価格・確認日・メモを記録し、単価で比較するウェブアプリです。
ビルド不要の静的ファイルのみで動作し、データはすべてブラウザ内（IndexedDB）に保存されます。サーバーには何も送信しません。

## GitHub Pages への設置
1. このフォルダの中身（index.html, style.css, app.js, icon.svg, icon-180.png）をリポジトリのルートに置く
2. Settings → Pages → Branch を `main` / `(root)` にして保存

## 使い方
- 「＋ 品名」で品名（例：小麦粉）を追加し、カードの「＋ 価格を記録」で店ごとの価格を登録
- 単位は g/kg/ml/L は100gまたは100mlあたり、m は1mあたり、個・枚などは1単位あたりで比較（税抜は税込に換算）
- 行をタップすると履歴の表示、同じ商品の新しい価格の記録、過去の記録の編集・削除ができる
- 各行右端のコピーボタンで、製造元・容量・入り数・税をコピーして別のスーパーの価格を記録（店は未登録の店が自動で選ばれる）
- 店舗名は「店舗」から変更・削除できる（支店は店名に含める）
- 「単位」から独自の単位を追加できる（数える単位、または g・ml・m に換算する重さ・容量・長さの単位）。価格の記録画面の単位欄からも追加可能。記録で使用中の単位は削除不可

## 更新時の注意
- ファイル更新時は index.html 内の `?v=` の値と app.js の `APP_VERSION` を同じ新しい値に変える（キャッシュ対策）
- 同期画面にバージョンが表示されるので、更新が反映されたか確認できる

## Mac と iPhone の同期
- 「同期」→「全データを書き出す」で JSON ファイルを保存（iPhone では共有シートから AirDrop や iCloud Drive へ）
- もう一方の端末で「ファイルを選んで読み込む」
  - 統合：ID ごとに更新日時の新しい方を残す（削除も反映）
  - 置き換え：読み込んだファイルの内容で全置換
- 書き出しファイルはそのままバックアップになる

## 長さ対応版（2026092903）
- 標準単位に m を追加。長さは1mあたりの税込価格で比較します（入り数も反映）。
- 独自単位の種類に「長さ」を追加。例：cm は換算量 0.01、mm は 0.001、km は 1000 と指定します。
- 既存データの保存先・形式・ID・更新日時は変更せず、データの移行や初期化は行いません。従来のJSONも読み込めます。
- すでに独自単位 m がある場合は、その定義を優先します（削除済みの定義も履歴の計算用に維持）。自動で長さに変更しません。この場合は別名の独自単位（例：メートル、種類：長さ、換算量：1）を追加して長さを記録できます。
- 更新は、現在と同じGitHub PagesのURLでファイルを差し替えてください。別のドメインやブラウザには保存済みデータは自動で移りません。
- 同期する端末もこの版へ更新してください。旧版は長さの独自単位を正しく比較できません。

## 入力フォームのフォーカス対策版（2026093001）
- 価格記録フォームを開く前に検索欄などの入力フォーカスを解除し、見出しを初期フォーカスにします。
- コピー後などに店舗・価格欄へ50ミリ秒後に強制フォーカスしていた処理を削除しました。フォームを開いた後、入力したい欄をタップしてください。
- 保存データ・価格計算・同期の処理は、長さ対応版から変更していません。
- ロジック検証済みですが、iPhone Safari実機での症状解消は未確認です。
