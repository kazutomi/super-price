# スーパー価格比較

品名ごとに、スーパー別の製造元・数量・価格・確認日・メモを記録し、単価で比較するウェブアプリです。
ビルド不要の静的ファイルのみで動作し、データはすべてブラウザ内（IndexedDB）に保存されます。サーバーには何も送信しません。

## GitHub Pages への設置
1. このフォルダの中身（index.html, style.css, app.js, icon.svg, icon-180.png）をリポジトリのルートに置く
2. Settings → Pages → Branch を `main` / `(root)` にして保存

## 使い方
- 「＋ 品名」で品名（例：小麦粉）を追加し、カードの「＋ 価格を記録」で店ごとの価格を登録
- 単位は g/kg/ml/L は100gまたは100mlあたり、個・枚などは1単位あたりで比較（税抜は税込に換算）
- 行をタップすると履歴の表示、同じ商品の新しい価格の記録、過去の記録の編集・削除ができる
- 各行右端のコピーボタンで、製造元・容量・入り数・税をコピーして別のスーパーの価格を記録（店は未登録の店が自動で選ばれる）
- 店舗名は「店舗」から変更・削除できる（支店は店名に含める）
- 「単位」から独自の単位を追加できる（数える単位、または g・ml に換算する重さ・容量の単位）。価格の記録画面の単位欄からも追加可能。記録で使用中の単位は削除不可

## 更新時の注意
- ファイル更新時は index.html 内の `?v=` の値と app.js の `APP_VERSION` を同じ新しい値に変える（キャッシュ対策）
- 同期画面にバージョンが表示されるので、更新が反映されたか確認できる

## Mac と iPhone の同期
- 「同期」→「全データを書き出す」で JSON ファイルを保存（iPhone では共有シートから AirDrop や iCloud Drive へ）
- もう一方の端末で「ファイルを選んで読み込む」
  - 統合：ID ごとに更新日時の新しい方を残す（削除も反映）
  - 置き換え：読み込んだファイルの内容で全置換
- 書き出しファイルはそのままバックアップになる
